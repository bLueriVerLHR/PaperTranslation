1. 基础原理与架构演进

序列表示、输入组织与位置表征

Transformer 的输入是向量序列，但形成序列的方式取决于研究对象。BERT 使用 WordPiece 将文本分解为词元，再把词元、片段和位置嵌入相加。文本对会拼入同一序列，以 [SEP] 分隔，并用片段嵌入区分两部分；因此，两个文本片段可以在同一次自注意力计算中交换信息，而不必先分别编码，再增加一个交互网络。这里的“句子”也不必是语言学意义上的完整句子，可以是连续文本片段。[1]

图像没有与词元天然对应的离散单位。ViT 将图像划分为不重叠的方形图块，展平后通过共享线性投影形成图块嵌入。设图像高、宽为 H、W，通道数为 C，图块边长为 P；在高、宽均可被图块边长整除时，图块数为：[2]

N=HWP2

每个展平图块有 P2C 个分量，经投影映射到统一的隐藏维度。ViT 还在序列前加入一个可学习的分类词元，并为各位置加入可学习的位置向量。分类头读取分类词元的输出，而不是直接对某一个图块作判断。这种设计把视觉识别接到序列编码器上，但图块边界仍是几何划分，不是物体或语义区域的边界。[2, 3]

位置向量承担的是让模型辨认空间布局的作用，不会自动提供卷积网络所具有的全部局部性或平移等变性。原始 ViT 使用一维可学习位置嵌入；迁移到更高分辨率时保持图块边长，图块数随之增加，并按原二维布局插值位置嵌入。因而，“模型可以处理更长序列”与“原位置参数可以原样复用”是两个不同问题。[2]

图块粒度同时影响表示与计算。在固定图像尺寸下，减小图块边长会增加序列长度，使更多细粒度位置进入全局交互，也扩大注意力矩阵。这不是把图像转成序列之后才出现的附带开销，而是输入组织本身参与了模型的资源分配。[2]

缩放点积注意力、多头注意力与交叉注意力

对单一输入序列的自注意力，可以从三个线性投影理解其分工：查询表示当前位置需要寻找什么，键用于计算匹配分数，值承载被汇聚的信息。若一头的查询、键维度为 dh，ViT 附录 A 使用的缩放点积形式为：[2]

A=softmax(QKTdh),Y=AV

这里 softmax 沿每个查询对应的键位置归一化。如果序列含 S 个位置，A 是 S×S 的权重矩阵，每个输出是值向量的加权和。多头注意力并行计算多组投影，将各头输出拼接后再投影；它不是把同一个注意力结果简单复制多份。[2]

相同的计算骨架仍可采用不同的可见性约束。BERT 在输入文本中使用双向自注意力；CLIP 的文本塔则保留因果自注意力。后者并不意味着 CLIP 的主任务是在生成描述，其实际目标是图文匹配。可见性、表征提取方式和训练目标必须分别辨认，不能仅凭“使用 Transformer”判断模型是否自回归生成。[1, 4]

稠密注意力的成对交互项随序列长度平方增长，但这只描述计算图中的一个部分。投影、前馈网络及硬件实现也影响代价；原 ViT 附录 D.4 特别比较了理论计算量与 TPU 上的速度。因此，不能把注意力矩阵缩小的比例直接解释为端到端加速比例。[2]

残差连接、归一化与前馈网络

ViT 的编码器交替使用多头自注意力与逐位置前馈子块，并在每个子块前应用 LayerNorm、在子块后加入残差连接。注意力负责位置之间的信息汇聚，前馈子块则对各位置的隐藏表示作非线性变换；原实现的前馈部分由两层线性变换与 GELU 构成。这种分工解释了为何序列长度的变化既影响注意力交互，也影响逐位置计算，不能只看注意力矩阵。[2]

编码器、解码器与编码器—解码器结构

“编码器”和“解码器”需要按计算职责理解，而不能只按模块名称归类。BERT 把文本转成上下文化表示，再为分类、序列标注或答案跨度预测附加相应输出层；ViT 则从图块序列提取图像表征。两者的输入和学习任务不同，但都可将序列编码与任务输出区分开来。[1, 2]

MAE 在预训练时增加重建模块：较大的编码器只处理可见图块，较轻的解码器接收编码结果及补入的掩码词元，并重建图块像素。下游识别使用编码器，重建解码器被移除。这里的“解码器”指图像重建职责，并不表示它采用自回归词元生成，也不能与翻译模型的解码器不加区分地视为同一种结构。[3]

CLIP 的图像塔与文本塔分别编码两种模态，再通过投影后的向量相似度建立联系；其图像塔既有 ResNet 变体，也有 ViT 变体。双塔共享的是对齐后的表征空间，不是两种模态之间逐层交叉注意力。对比学习由此可以发生在独立编码器之间，而不要求先构造一个联合图文序列。[4]

2. 预训练阶段

目标函数与监督信号

预训练的共同点是先从较大范围的数据学习可迁移的表示，而不是必须采用同一种监督形式。原始 ViT 的主要结果来自有标签的图像分类预训练；BERT 从文本构造词元预测与文本关系任务；MAE 从部分可见图像恢复像素；CLIP 则判断图像与文本是否配对。它们的差异首先在于“哪些信息作为输入、什么作为预测目标”，其次才是模型规模。[1–4]

遮挡预测：相近的任务形式，不同的计算图

BERT 的掩码语言模型并非让每个词元预测自身。训练时先选择 15% 的 WordPiece 位置作为预测目标；这些位置中，80% 替换为 [MASK]，10% 替换为随机词元，10% 保持原样。目标始终是原词元，损失只在选定位置计算。因而，15% 是目标位置比例，不是输入中实际出现 [MASK] 的比例。[1]

设原词元序列为 x，扰动后的输入为 x~，被选作目标的位置集合为 M，平均预测损失可以写为：[1]

LMLM=−1|M|∑i∈Mlogpθ(xi|x~)

原版 BERT 还使用下一句预测：一半样本的第二段来自真实后续文本，一半随机取自语料，再依据 [CLS] 表示作二元分类。训练损失由平均掩码预测损失和平均下一句预测损失相加组成。该任务是原版方法的一部分，其消融结果应放回原语料、模型和下游任务中解释，而不是由此要求所有 Transformer 都使用下一句预测。[1]

MAE 也构造缺失信息，但不把掩码词元送入较大的编码器。它先移除随机选出的图块，只编码可见部分，再向较轻的重建模块补入掩码词元及位置向量。损失仅比较被遮挡图块的预测像素与原像素。这里用 M 表示被遮挡图块的索引集合。令 xi 为一块含 q 个像素分量的向量，忽略可选的图块内像素归一化时，这一像素均方误差可表述为：[3]

LMAE=1|M|q∑i∈M‖x^i−xi‖22

两类掩码学习因此不能只按遮挡比例比较。BERT 的编码器仍处理完整的扰动序列，输出离散词表上的预测；MAE 的编码器只处理可见图块，重建模块输出连续像素。MAE 作者以自然图像的空间冗余解释高比例遮挡的动机，并在其 ViT 与训练设置中发现 75% 遮挡有效；这不是所有视觉输入或序列任务的通用最优比例，也不意味着像素重建自然等价于语义理解。[1, 3]

配对判别：学习对齐而非生成描述

CLIP 使用图文对中的对应关系作为监督。在含 B 个配对样本的批次中，图像塔与文本塔分别提取特征，经线性投影和 L2 归一化得到 ui 与 vj。配对分数是余弦相似度乘以学习的正尺度 α：[4]

sij=αuiTvj,α>0

对每个图像，把与之配对的文本作为批内分类目标；反向再对每个文本预测配对图像。两个方向的交叉熵取平均，使匹配约束同时作用于两种检索方向。这里监督的是整对样本的相对匹配，不是逐词生成描述，也不是对所有批内不配对样本给出语义无关的判定。批内负例是损失构造中的角色，不能不加区分地当作真实世界的排斥关系。[4]

单模态与多模态数据组织

数据组织决定哪些学习信号能够被构造出来。BERT 使用 BooksCorpus 与英文 Wikipedia 的连续文本；文档顺序既提供较长上下文，也使真实后续文本与随机文本的关系任务成为可能。把语料只保留成打乱的独立句子，会改变这种监督所依赖的条件。[1]

视觉预训练则需要区分图像本身与标签。ViT 的主实验比较不同规模的带标签数据，包括 ImageNet、ImageNet-21k 和 JFT-300M；MAE 在 ImageNet-1K 上不使用类别标签构造重建任务，但评估时的识别微调仍使用监督。于是，“预训练不依赖标签”并不等于整个学习与评测流程都没有标签。[2, 3]

CLIP 从互联网构造约四亿图文对，文本提供比固定类别标签更开放的概念描述，却仍是一种监督来源。它不要求每个样本对应一个人工定义的类别，并不意味着配对无噪声、没有筛选偏差或对所有概念覆盖均衡。其数据检索与筛选、英文文本条件和评测重叠分析，都属于解释迁移结果所需的背景。[4]

优化、训练稳定性与规模扩展

模型规模、数据规模与学习任务需要联合讨论。ViT 在原论文的小数据设置中不占优势，增加预训练数据后较大模型才更充分地发挥容量；这组实验说明的是特定架构、数据和正则化条件下的规模关系，不是证明任何任务只要扩大数据就会消除结构偏置的价值。原论文也另行探索掩码自监督，但不能用这部分探索重述以有标签训练为主的结果。[2]

MAE 的效率来源更直接地落在计算图上：高比例移除图块减少了大编码器的输入长度，完整图块集则由较轻的重建模块处理。这既减少逐位置计算，也缩小编码器的注意力交互项；但完整模型还包含投影、前馈和重建开销。原文表2的实际训练加速有具体 TPU、框架、模型、遮挡比例及解码器条件，不能从序列长度平方关系推算出一个通用加速倍数，更不能把预训练加速写成下游完整图像推理的同倍加速。[3]

损失参数化也参与优化。CLIP 学习相似度的正尺度，而不是固定所有分数的幅度；这一尺度改变两个方向分类损失中的竞争强度。训练目标、数据规模、图像编码器选型与文本编码器设计共同构成其方法，不能把跨模型结果简化成“换用 Transformer 就取得了全部收益”。[4]

预训练评估与跨任务迁移

预训练损失与可迁移表示不是同一个评价对象。BERT 将同一个预训练参数初始化用于不同任务，再分别微调任务模型；原文还比较冻结特征后训练任务网络的方式。ViT 则替换分类头并在目标任务上微调，也用冻结表示的少样本线性评估观察数据规模的影响。这些协议改变的参数不同，不能将各自分数视为同一种迁移能力。[1, 2]

MAE 的像素重建模块在识别时被移除，编码器接收完整图像的图块。因此，下游迁移验证的是编码器能否在新的监督目标下提供有用表示，而不是重建图片是否看起来逼真。原文关于线性探测与部分微调的比较进一步表明：冻结特征的线性可分性与经过非线性适配后的表现可能产生不同排序。只以线性探测或只以重建质量评价预训练，都会遗漏另一部分能力。[3]

CLIP 的零样本分类提供另一种接口：把目标类别名称或描述输入文本塔，与图像表示比较相似度，以文本构造分类器，而不在目标训练样本上拟合分类权重。“零样本”限定的是目标任务的这种适配方式，不是否认预训练已使用大规模图文监督。它还依赖候选类别与描述模板；原作者明确承认开发中反复观察验证集，不能将该过程描写成完全没有评测反馈的模型或提示选择。[4]

这些迁移接口各自暴露不同限制。文本理解的有监督微调、视觉表示的线性探测、完整模型微调和文本驱动的零样本分类，回答的不是同一个问题。CLIP 在部分专业或复杂任务上表现较弱，类别设计还影响偏差；MAE 的重建目标与识别目标之间需要适配；ViT 的原始规模实验受数据与训练配方限定。跨研究综合应先辨认目标、输入与适配协议，再讨论共同趋势，而不是把不同任务上的最高分并列成统一排名。[2–4]
