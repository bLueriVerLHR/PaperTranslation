Efficient Memory Management for Large Language Model Serving with PagedAttention

摘要译文

高吞吐地服务大型语言模型（LLM）需要一次批处理足够多的请求。然而现有系统难以做到这一点，因为每个请求的键值缓存（KV cache）都非常大，并且会动态地增长和收缩。如果管理不当，这些内存会因碎片化与冗余复制而被严重浪费，从而限制批大小。为解决这一问题，我们提出 PagedAttention，一种受操作系统中经典虚拟内存与分页技术启发的注意力算法。在它之上，我们构建了 vLLM，一个 LLM 服务系统，实现了（1）KV cache 内存接近于零浪费，以及（2）请求内部与请求之间灵活的 KV cache 共享，以进一步降低内存占用。评测表明，在最先进的系统（如 FasterTransformer 与 Orca）的同等延迟水平下，vLLM 把主流 LLM 的吞吐提升了 2–4 倍。序列越长、模型越大、解码算法越复杂，这一提升越明显。vLLM 的源代码公开在 https://github.com/vllm-project/vllm 。

阅读说明与边界

摘要中的关键数字：同等延迟水平下吞吐比 FasterTransformer、Orca 等当时最优系统提升 2–4 倍，且序列越长、模型越大、解码算法越复杂收益越明显。SOSP 2023。vLLM 已成为当前开源推理服务的事实标准，其分页思想后来也影响了前缀缓存（prefix caching）与 KV cache 卸载等一整类工作。
