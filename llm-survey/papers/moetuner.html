摘要译文

混合专家（MoE）架构已成为在扩展 Transformer 模型时兼顾效率的一种有前景的方案，它以稀疏激活在增加模型容量的同时降低计算成本。然而，随着 MoE 模型规模增大，它们需要跨 GPU 设备分布，因而因巨大的内存占用而面临关键的性能瓶颈。专家并行把专家分布到各 GPU 上，却面临若干关键挑战，包括不均衡的 token 路由与专家激活，导致通信长尾延迟与处理低效。已有方案解决了其中部分问题，但未能同时解决负载不均衡与通信倾斜这对双重挑战。不同专家之间 token 处理负载的不均衡，导致不同 GPU 的处理时间不等；而 GPU 之间的通信倾斜则导致跨卡数据传输不均衡。这些因素通过增加长尾延迟、降低整体吞吐，劣化了 MoE 模型的性能。为突破这些限制，我们提出一个整数线性规划（ILP）形式化，联合考虑 token 负载、通信与计算成本来优化专家放置。我们利用了跨层存在 token 路由依赖这一性质：被路由到某一层某个专家的 token，在随后各层中很可能被路由到一小组有限的专家。我们的方案 MoETuner 给出了最优的专家到 GPU 分配，最小化跨 GPU 的 token 路由成本并平衡各设备上的 token 处理，从而降低长尾延迟与端到端执行时间。实验结果表明，单节点与多节点推理分别取得 9.3% 与 17.5% 的端到端加速，显示了我们的 ILP 优化为下一代 MoE 提供专家并行方案的潜力。

阅读说明与边界
