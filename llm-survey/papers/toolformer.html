摘要译文

语言模型尤其在规模增大后，展现了仅凭少量示例或文本指令解决新任务的强大能力。但矛盾的是，它们在算术或事实查找等基础功能上仍很吃力，而更简单、更小的模型却擅长这些功能。本文表明，语言模型可以通过简单 API 自学使用外部工具，兼取两者优势。我们提出 Toolformer，使模型学会决定调用哪些 API、何时调用、传递哪些参数，以及如何将结果最好地纳入后续 token 预测。这通过自监督完成，每个 API 只需少量演示。我们加入计算器、问答系统、两个不同搜索引擎、翻译系统和日历等工具。Toolformer 在多种下游任务上显著改善零样本表现，常可与大得多的模型竞争，同时不损害核心语言建模能力。
