摘要译文

大语言模型（LLM）的训练规模已经达到数万张 GPU，并且仍在持续扩大，以便更快地学习更大的模型。伴随资源规模扩张而来的是故障的普遍化（CUDA 错误、NaN 值、作业挂起等），这给训练稳定性带来了重大挑战。任何大规模 LLM 训练基础设施都应当追求最小的训练中断、高效的故障诊断与有效的容错，从而实现高效率的持续训练。本文提出 ByteRobust，一个为 LLM 稳健稳定训练而量身打造的大规模 GPU 基础设施管理系统。它利用 LLM 训练过程的独特性，把检测与恢复故障当作常规工作来优先处理。借助 LLM 训练所用的并行方式及其特征，ByteRobust 实现了高容量容错、迅速的故障分界与定位，并采用有效的数据驱动方法，全面保障 LLM 任务持续高效地训练。ByteRobust 已部署在一个生产 GPU 平台上，在 9,600 张 GPU 上运行三个月的训练作业取得了 97% 的 ETTR。

阅读说明与边界

97% ETTR 是厂商在生产 GPU 平台上对其 9,600 张 GPU、三个月训练作业报告的结果，属于生产自报指标；ETTR 的定义依赖该文给出的口径，不应与其它指标直接换算或横比。
