摘要译文

LLM 越来越多地作为目标驱动 Agent 与游戏、编译器、API 等外部环境交互。然而，传统强化学习需要大量训练样本和昂贵的微调，使语言 Agent 难以快速高效地从试错中学习。我们提出 Reflexion：不更新权重，而通过语言反馈强化 Agent 的新框架。具体而言，Reflexion Agent 对任务反馈信号进行文字反思，并将自己的反思文本保留在情景记忆缓冲中，以改善后续尝试的决策。Reflexion 足够灵活，可结合标量或自由文本等不同类型、以及外部或内部模拟等不同来源的反馈，在顺序决策、编码和语言推理等多种任务上相对基线 Agent 获得显著提升。例如，它在 HumanEval 编码基准上达到 91% 的 pass@1 准确率，超过此前 GPT-4 的 80%。我们还对不同反馈信号、反馈纳入方式与 Agent 类型进行消融和分析，解释它们如何影响表现。
