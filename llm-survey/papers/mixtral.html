摘要译文

我们提出 Mixtral 8x7B，一个稀疏混合专家（SMoE）语言模型。Mixtral 的架构与 Mistral 7B 相同，区别在于每一层由 8 个前馈块（即专家）组成。对每个 token、在每一层，路由器网络选择两个专家来处理当前状态并组合其输出。尽管每个 token 只看到两个专家，但被选中的专家在每个时间步可以不同。结果是：每个 token 可以访问 47B 参数，但在推理时只使用 13B 激活参数。Mixtral 以 32k token 的上下文长度训练，在所有评测基准上优于或匹配 Llama 2 70B 与 GPT-3.5。特别是在数学、代码生成与多语言基准上，Mixtral 大幅优于 Llama 2 70B。我们还提供了一个用于指令跟随的微调模型 Mixtral 8x7B-Instruct，在人工基准上超过了 GPT-3.5 Turbo、Claude-2.1、Gemini Pro 与 Llama 2 70B-chat。基座模型与指令模型均以 Apache 2.0 许可发布。

阅读说明与边界

批内活跃专家并集扩大不等于每个 token 计算全部专家；需分开看 FLOPs、权重访问、GEMM 利用率、通信和 KV 容量。
