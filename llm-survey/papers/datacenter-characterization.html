摘要译文

大语言模型（LLM）在多项变革性任务上表现出色。然而，要高效利用大规模集群资源来开发 LLM 绝非易事，其中往往充满频繁的硬件故障、复杂的并行策略与不均衡的资源利用等挑战。本文给出一项深入的刻画研究，所用数据是从我们的 GPU 数据中心 Acme 采集的六个月 LLM 开发负载 trace。具体而言，我们考察了 LLM 与以往任务特定深度学习（DL）负载之间的差异，探索资源利用模式，并识别各类作业失败带来的影响。我们的分析总结了遇到的障碍，并揭示了为 LLM 定制优化系统的潜在机会。此外，我们介绍了自己的系统工作：（1）容错预训练，通过 LLM 参与的故障诊断与自动恢复来增强容错能力；（2）面向评估的解耦调度，通过试验分解与调度优化实现及时的性能反馈。

阅读说明与边界

六个负载 trace 来自论文自建的数据中心 Acme，故障率、资源利用率与并行策略分布刻画的是该集群与那半年，不是所有 GPU 集群的普遍水平。文中「容错预训练」「解耦调度」是作者据此提出的系统工作，其收益需按各自实验条件阅读。
