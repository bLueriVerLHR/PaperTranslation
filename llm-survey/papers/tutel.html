摘要译文

稀疏门控混合专家（MoE）已被广泛用于在固定计算成本下把深度学习模型扩展到万亿以上参数。MoE 的算法性能依赖于其 token 路由机制：把每个输入 token 转发到正确的子模型或专家。虽然 token 路由会在运行时动态决定专家负载量，现有系统却因静态执行——即静态的并行与流水线——而遭受低效计算，无法适应这种动态负载。我们提出 Flex，一套可高度扩展的 MoE 栈设计与实现，具备动态自适应的并行与流水线。Flex 为 MoE 模型参数与输入数据的分布设计了统一布局，所有可能的并行或流水线方法都能复用该布局，且不产生任何数学不等价或张量迁移开销。这使得运行时可以零成本地做自适应并行/流水线优化。基于这一关键设计，Flex 还实现了多种 MoE 加速技术。综合所有技术，Flex 在任意规模上都交付了巨幅加速——相比此前最先进方案，单层 MoE 在 16 张与 2048 张 A100 上分别取得 4.96x 与 5.75x 加速。我们的评估表明 Flex 能高效运行一个真实的 MoE 模型 SwinV2-MoE。效率上，Flex 使 SwinV2-MoE 相比 Fairseq 在训练与推理上分别取得最高 1.55x 与 2.11x 加速；效果上，SwinV2-MoE 在预训练与 COCO 目标检测等下游视觉任务上都优于对应的稠密模型，说明 Flex 已可用于端到端的真实模型训练与推理。

阅读说明与边界

单层 MoE 在 16 张与 2048 张 A100 上相对此前最先进方案分别取得 4.96x 与 5.75x 加速；SwinV2-MoE 在训练与推理上相对 Fairseq 最高 1.55x 与 2.11x。是「MoE 的效率损失来自静态系统而非稀疏算法本身」这一判断的代表作。
