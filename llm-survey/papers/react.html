摘要译文

尽管 LLM 在语言理解与交互决策任务上表现突出，它们的推理能力（如 chain-of-thought prompting）与行动能力（如生成动作计划）主要被分开研究。本文探索让 LLM 交错生成推理轨迹与任务特定动作，以形成更强协同：推理轨迹帮助模型形成、跟踪和更新行动计划并处理异常；动作则让模型与知识库或环境等外部来源交互，获取更多信息。我们将这一方法命名为 ReAct，并应用于多种语言和决策任务，展示了相对最先进基线的有效性，以及相比缺少推理或行动组件方法更好的可解释性与可信度。具体而言，在 HotpotQA 问答和 Fever 事实核验上，ReAct 通过简单的 Wikipedia API 交互，克服 chain-of-thought 中常见的幻觉与错误传播问题，并产生比无推理轨迹基线更易解释、类似人类的任务求解轨迹。在 ALFWorld 和 WebShop 两个交互决策基准上，仅提供一两个上下文示例，ReAct 就比模仿学习和强化学习方法分别高出 34 和 10 个百分点的成功率。项目网站提供代码。
