摘要译文

混合专家（MoE）在提升性能、降低计算复杂度的同时，展现出扩展大语言模型（LLM）的巨大潜力。然而，其稀疏激活的架构使前馈网络（FFN）在推理阶段从计算密集转向访存密集，导致 GPU 利用率显著下降、运营成本升高。我们提出 MegaScale-Infer，一个用于大规模 MoE 模型服务的高效且经济的系统。MegaScale-Infer 在模型的每一层内把注意力与 FFN 模块分离，使两者可以独立扩展、采用量身定制的并行策略并异构部署。为在 MoE 稀疏性下充分发挥分离架构的优势，MegaScale-Infer 引入乒乓流水线并行：把请求批次划分为微批，让它们在注意力与 FFN 之间往返以完成推理。结合为每个模块分别设计的模型并行方式，MegaScale-Infer 能有效隐藏通信开销并最大化 GPU 利用率。为适配分离后的注意力与 FFN 模块、并把数据传输开销（例如 token 派发）降到最低，MegaScale-Infer 提供了一个高性能的 M2N 通信库，它消除了不必要的 GPU 到 CPU 数据拷贝、组初始化开销与 GPU 同步。实验结果表明，MegaScale-Infer 的每 GPU 吞吐相对当时最先进的方案最高提升 1.90 倍。

阅读说明与边界

该文为 arXiv 预印本，未经同行评审。1.90 倍每 GPU 吞吐提升是论文相对当时最先进方案在其实验设置下的对比，分离式部署还会增加调度与通信复杂度，不能仅凭该倍数决定是否拆分注意力与 FFN。
