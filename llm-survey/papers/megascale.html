摘要译文

本文介绍构建并部署 MegaScale 的设计、实现与工程经验。MegaScale 是一个在超过一万张 GPU 的规模上训练大语言模型的生产系统。在这一规模上训练 LLM 给训练效率与稳定性带来了前所未有的挑战。我们采用全栈方法，协同设计模型块与优化器结构、计算与通信重叠、算子优化、数据流水线与网络性能调优等算法与系统组件。考虑到 LLM 训练作业的持续时间很长，在训练全过程中保持高效率（即稳定性）在生产中是重要考量。许多棘手的稳定性问题只有在大规模下才会暴露，而深入的可观测性是解决它们的关键。我们开发了一套诊断工具，用于监测系统深层组件与事件、定位根因，并据此得出实现容错、缓解慢节点的有效技术。在 12,288 张 GPU 上训练 175B 语言模型时，MegaScale 达到 55.2% 的模型 FLOPs 利用率（MFU），相对 Megatron-LM 把 MFU 提升了 1.34 倍。我们分享了在识别与修复故障、慢节点方面的运维经验。希望从系统视角阐明这些问题、分享这些经验，能启发后续的 LLM 系统研究。

阅读说明与边界

55.2% MFU 与 1.34 倍提升是论文在 12,288 张 GPU、175B 模型与其自建网络下的结果；MFU 同时取决于模型、并行策略、网络与数据流水线，不能当作跨集群排行榜，也不保证同样配置在别处可复现。诊断工具与慢节点经验属于该生产平台的具体实践。
