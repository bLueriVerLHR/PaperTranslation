摘要译文

把语言模型变得更大，并不会自然地让它更善于遵循用户意图。例如，大型语言模型可能生成不真实、有毒或对用户毫无帮助的输出。换言之，这些模型与它们的用户并不对齐。在本文中，我们展示了一条通过在广泛任务上用人类反馈进行微调，使语言模型与用户意图对齐的路径。我们从标注员编写的提示词以及通过 OpenAI API 提交的提示词出发，收集了一批标注员演示「期望模型行为」的数据集，用它以监督学习方式微调 GPT-3。随后我们收集了一批模型输出排序数据，用它通过基于人类反馈的强化学习进一步微调这个监督模型。我们把得到的模型称为 InstructGPT。在针对我们提示分布的人类评测中，13 亿参数的 InstructGPT 模型的输出比 1750 亿参数的 GPT-3 更受偏好，尽管参数量少了 100 倍。此外，InstructGPT 模型在真实性上有所提升、有毒输出减少，同时在公开 NLP 数据集上的性能几乎没有退化。尽管 InstructGPT 仍会犯简单错误，但我们的结果表明，用人类反馈做微调是一条很有前景的语言模型对齐方向。

阅读说明与边界

摘要中最具冲击力的数字：13 亿参数的 InstructGPT 输出在人类评测中比 1750 亿参数的 GPT-3 更受偏好，参数量少 100 倍。同时真实性提升、有毒输出减少，公开 NLP 数据集性能几乎不退化。这份工作是 RLHF 范式的奠基性工程实现，也确立了「SFT → 奖励模型 → RL」的三段式流程；后续 DPO 等工作正是针对其中 RL 阶段复杂且不稳定的问题提出的。
