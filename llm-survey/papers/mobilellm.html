摘要译文

本文回应因云成本上升和延迟顾虑而增长的移动设备高效 LLM 需求。我们关注十亿参数以下的高质量语言模型，这是移动部署的实际选择。与强调数据和参数数量决定模型质量的普遍看法不同，我们的研究凸显了架构对十亿参数以下 LLM 的重要性。利用深而窄的架构、embedding sharing 和 grouped-query attention，我们建立了强基线 MobileLLM，相比此前最先进的 125M/350M 模型，准确率分别提升 2.7%/4.3%。此外，我们提出即时逐块权重共享，不增加模型大小，只引入轻微延迟开销。得到的 MobileLLM-LS 相比 MobileLLM 125M/350M，准确率进一步提升 0.7%/0.8%。MobileLLM 系列还在聊天基准上明显优于此前的十亿参数以下模型，在 API 调用任务上的正确性接近 LLaMA-v2 7B，展示了小模型在常见端侧场景中的能力。
