摘要译文

混合专家（MoE）架构把大语言模型扩展到数千亿参数。服务单个 MoE 模型需要多张 GPU 并行，通常通过张量并行（TP）或专家并行（EP）。最优选择取决于在途请求数：低并发时 TP 更快，高并发时 EP 胜出。生产负载会持续跨越这条边界：在线服务存在突发到达随后归于平静的过程，而强化学习 rollout 以高并发突发开始、随后衰减为一个长尾的慢请求。因此，固定任何一种布局都会在负载跨越到另一侧时损失性能。我们提出 Moebius，一个能在运行时于 EP 与 TP 之间切换、且无需重启引擎或丢弃在途请求的服务系统。我们的关键洞察是：EP 与 TP 是同一个模型的两套布局，而不是两个模型——它们在字节相同的专家权重与 KV cache 上计算同一个函数，因此切换只改变每个 rank 拥有的切片归属。搬运这些归属发生变化的切片是唯一不可削减的成本，而现代高带宽 GPU 互联让它快到足以在两个解码步之间完成，无需排空在途请求。Moebius 为每套并行布局保留其运行时常驻状态，并用融合的 GPU 到 GPU 传输 kernel 在固定地址处重新分片唯一的专家权重与 KV cache 副本。在 8×H200 GPU 上服务 Qwen3-235B-A22B，Moebius 在每个工作点上都不劣于更优的那种静态并行布局，并在 RL rollout 上比其快 1.16–1.25x。每次切换在 215–434 ms 内完成，且 Moebius 同时常驻两套布局只多占 2.4% 显存。

阅读说明与边界
