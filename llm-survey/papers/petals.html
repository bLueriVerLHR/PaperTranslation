摘要译文

许多 NLP 任务受益于往往超过千亿参数的大语言模型。随着 BLOOM-176B 和 OPT-175B 发布，任何人都能下载这一规模的预训练模型，但使用它们仍需要许多研究者无法获得的高端硬件。在一些情况下，可通过 RAM 卸载或托管 API 更便宜地使用 LLM，然而这些技术有固有限制：卸载对交互推理而言太慢，而 API 对需要访问权重、注意力或 logits 的研究不够灵活。我们提出 Petals，通过汇聚多方资源来协作进行大模型推理和微调。我们证明，对非常大的模型，这一策略优于卸载：在消费级 GPU 上，BLOOM-176B 推理约每秒一步，足以支持许多交互式 LLM 应用。不同于多数推理 API，Petals 还原生暴露所服务模型的隐藏状态，允许基于高效微调方法训练并分享自定义模型扩展。
