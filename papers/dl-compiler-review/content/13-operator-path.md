# 贯穿对照：一次融合注意力在六个栈里的落点 {#operator-path}

按栈展开的各章之后，“中间表示”与“计算图”两章横向比较了表示与图技术。这一章再换一个方向：拿同一个算子走一遍，看它在每一处被改写成什么、谁做的决定、代价从哪里来。选注意力是因为它同时压住前面讨论过的每一种机制——两次矩阵乘、一次跨行归约、随序列长度平方增长的空间、以及一个只有在分块之后才成立的数值递推。六个栈对它的处理方式差异明显，差异的位置恰好就是各栈的自定义边界。LLVM 与 MLIR 不实现这个算子，所以只在它们真正参与的位置被提到：前者承接中端与后端，后者决定谁能往管线里加一层。
