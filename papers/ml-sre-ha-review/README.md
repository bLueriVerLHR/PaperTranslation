- slug：`ml-sre-ha-review`；类型：原创综述（`kind: review`）。

## 重建

```powershell
python tools/dev.py run -- dist\ml-sre-ha-review\work\rebuild.py
python tools/dev.py run -- tools/manuscript_check.py --paper ml-sre-ha-review
```

`rebuild.py` 从**未解析**路径定位流水线根，再解析工作树；`dist/` 是指向外部数据根的目录联接时，这样才不会把工作树解析到检出之外。
