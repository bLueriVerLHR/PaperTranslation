# 原创综述的研读与证据组织

本指南用于原创综述的资料整理、论证和审校，不是阅读页正文模板。它借鉴 Feynman 的文献综述、来源比较、引文核查与研究审校方法，并结合本项目的源稿、离线阅读和权利边界。不同综述保持各自的身份与论述结构；共享方法不要求合并成一个文献汇总站。原创综述写作或精修前必须完整阅读本指南与 [中文写作原则](chinese-writing.md)，涉及实现解读时另完整阅读 [源码解读规范](source-analysis.md)。机制解释的深度、数学前提与正文表达以写作规范为准，不能只完成来源清单而省去论证。

## 先明确问题，再组织文献

每个主题先确定需要解释的对象和问题。例如，架构主题可以问“信息如何在序列中传播”，推理主题可以问“计算和状态分别消耗什么资源”。围绕这些问题选择原始方法论文、评测、代码和综述，不按论文数量或发表声望替代相关性判断。

章节按研究对象与论证关系组织，不固定主题数量，也不默认所有任务都有同一种预训练、后训练和服务流程。语言、视觉、音频、时间序列、生物序列及多模态设置要分别辨认；自回归语言模型的 KV 缓存需求不自动成为所有模型的共同前提。

## 保存断言到证据的联系

研读记录应能说明：哪项断言由哪一个固定版本、章节、图表或代码支持，材料提供的是报告结果、推导、实现说明还是独立实验。书目身份至少核对题名、作者、稳定标识与实际版本；同题预印本和正式版分别记录，近似题名不任意替换。

有条件时以另一书目索引交叉核对身份。索引不可用、作者未能核对或 URL 失效时记录缺口，不补造字段。已有可核对的离线 PDF 不因网页不可达而失去证据资格；原始参考文献也不因工具匹配失败就被静默删除。

引文要支持所附的具体数字、条件或结论，不能只证明主题相关。尤其区分：原论文结果、综述归纳、厂商声明、代码静态观察和本项目分析。单一原始研究仍可作为其方法的来源，但重要的跨研究结论应寻找独立佐证，或保留单一来源和条件的限制。

## 比较一致、分歧与尚不明确之处

对照记录可按研究对象、方法作用点、训练与输入条件、证据类型及局限组织。表格用于帮助发现差异，不强制每篇论文填满相同栏目，也不直接代替正文中的机制解释。

看似冲突的结果先检查模型、数据、硬件、序列长度、批量和指标定义是否一致。参数少、FLOPs 少、内存少、时延低与能耗低是不同结论；跨论文数字不能无条件拼成排名。一个方法在特定任务上有效，也不能直接写成跨模态或跨设备保证。

研究综合应说明哪些结论有共同支持、哪些分歧来自设定不同、哪些缺少足够证据。不要以语气弱化代替核对，也不要为让分类整齐而把缺失证据填成肯定结论。

## 从原文与实现相互核对

涉及代码的断言应记录固定提交和相关实现位置，分别检查默认配置、数据处理、训练目标与输出计算。静态阅读不能写成已经训练、复现或测得性能。原论文未公开必要代码时，指出核对边界，不推测实现来补齐方法。

数学解释保留假设、维度与等价／近似条件。图示和例子用于澄清机制，不能将示意数字当作实测结果；制作原创示意时明确其性质。阅读页遵循原生 MathML 和真实相对资源文件，不因外部工具建议而引入运行时数学或绘图库。

## 审校分层，而非机械套版

可以把研究、来源核查、论证审校和写作看成不同检查职责；这不要求实际启动多个代理。是否委派仍由任务授权及环境约束决定。

- **关键问题**：身份错误、数字无来源、数学不成立、遗漏关键条件或把未经验证结果写成复现。进入正文前解决，不能以引用链接存在来掩盖。
- **主要问题**：覆盖不足、比较不公平、解释与证据脱节、重要分歧缺少处理。补充来源或缩小论断范围。
- **次要问题**：术语、指代、结构、重复或排版。修订时不损伤原始公式、代码、表格与引用。

任务中的待查项和审校记录留在任务状态或研究笔记；正文围绕技术对象连贯解释，不展示工作清单、审稿对话或固定问答脚本。中文表达参照 [中文写作原则](chinese-writing.md)。

## 原创解释与保留来源分开

外部论文的完整译文可以作为本地研究来源保存，但不是原创综述的正文。专题重组需要重新组织论证和准确归属，不把译文复制成新综述，也不沿用原论文的“我们”来指代本项目。

材料公开可访问、代码开源、原文获提供、引用得到核对，都不自动授予译文或图表的公开许可。版本、权利和必要的核对限制保留在资料记录与阅读元数据中；发表审批独立于研究资格。来源的保存与迁移应保护原稿和有用资料，不能用审校名义改写原始记录。

## 来源记录与工具边界

规范源稿、书目和有用研究笔记保留在各项目 `work/` 中；一次性计划、抓取原始响应、扫描报告和试验使用系统 TEMP。来源记录可列出接受和未接受的材料及理由、固定版本、实际核对范围和未决事项，不因多个角色重复同一来源而夸大证据数量。

借鉴研究工具的方法不等于执行其安装脚本、加载其扩展或发送本地数据。需要实际工具运行时，先核查依赖、遥测、凭据、费用与数据流，并使用隔离环境；原稿和私有资料不默认上传。
